# 블럭라이브러리 (Block Library)

어른들을 위한 레고 구독형 렌탈 플랫폼

## 프로젝트 정보
- **유형**: 구독형 렌탈 플랫폼
- **타겟 사용자**: 20~40대 키덜트
- **수익 모델**: 월 구독료 기반

## 핵심 기능
- 체험형 1회 렌탈 (구독 전 체험)
- 등급별 구독 플랜 (횟수·한정판 차등)
- '좋아요' 기반 취향 매칭 시스템
- 조립 후기 커뮤니티
- 어드민 관리 페이지

## 폴더 구조 (5개 팀)
- `planning/` — 기획 팀: 무엇을 만들 것인가
- `design/` — 디자인 팀: 어떻게 보여줄 것인가
- `cx/` — CX 팀: 누가 어떻게 사용할 것인가
- `marketing/` — 마케팅 팀: 어떻게 알릴 것인가
- `strategy/` — 전략 팀: 어떻게 지속 가능하게 만들 것인가
