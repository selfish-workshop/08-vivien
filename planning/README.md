# 기획 (Planning)

이 폴더는 "무엇을 만들 것인가"의 상세를 담습니다.

## 기능 목록과 MVP 우선순위

### Phase 1 — MVP (첫 출시에 반드시 필요)

| 우선순위 | 기능 | 설명 |
|---------|------|------|
| P0 | 회원가입/로그인 | 소셜 로그인(카카오, 네이버) 지원 |
| P0 | 레고 카탈로그 | 전체 레고 세트 목록 탐색, 테마·난이도·조각수 필터 |
| P0 | 체험형 1회 렌탈 | 구독 없이 1회 단건 렌탈 신청 (신규 유저 전용) |
| P0 | 구독 플랜 선택·결제 | 베이직/프리미엄/VIP 중 선택 후 월 결제 |
| P0 | 배송·반납 관리 | 배송 현황 조회, 반납 신청, 반납 확인 |

### Phase 2 — 핵심 경험 강화 (출시 후 1~2개월)

| 우선순위 | 기능 | 설명 |
|---------|------|------|
| P1 | '좋아요' 취향 매칭 | 카탈로그에서 좋아요 누른 데이터 기반으로 매달 배송 세트 자동 매칭 |
| P1 | 마이페이지 | 구독 현황, 렌탈 히스토리, 취향 프로필 확인·수정 |
| P1 | 어드민 페이지 (기본) | 상품 등록·수정, 구독자 관리, 배송 상태 관리 |

### Phase 3 — 커뮤니티·성장 (출시 후 3~6개월)

| 우선순위 | 기능 | 설명 |
|---------|------|------|
| P2 | 조립 후기 커뮤니티 | 완성작 사진 업로드, 후기 작성, 좋아요·댓글 |
| P2 | 한정판 전용 큐레이션 | VIP 구독자 대상 한정판·콜라보 세트 우선 배정 |
| P2 | 알림 시스템 | 배송 출발, 반납 기한, 신규 세트 입고 알림 |
| P2 | 어드민 페이지 (고급) | 매출 대시보드, 취향 분석 통계, 재고 관리 |

## 구독 플랜 구조

| 플랜 | 월 배송 | 한정판 접근 | 주요 혜택 |
|------|--------|-----------|----------|
| 베이직 | 1회 | X | 기본 세트 랜덤 배송 |
| 프리미엄 | 2회 | O (일부) | 테마 선호 반영, 프리미엄 세트 포함 |
| VIP | 3회 | O (전체) | 한정판 우선 배정, 전용 커뮤니티 |

---

## MVP 범위 요약

**포함 (Phase 1)**
- 회원가입·로그인 → 카탈로그 탐색 → 체험 렌탈 or 구독 → 결제 → 배송·반납

**제외 (Phase 2 이후)**
- 취향 매칭 알고리즘, 커뮤니티, 한정판 큐레이션, 고급 어드민

> MVP의 핵심 목표: "가입 → 체험 → 구독 전환"의 흐름이 끊김 없이 작동하는 것
